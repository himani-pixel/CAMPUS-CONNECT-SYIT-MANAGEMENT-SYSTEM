# CAMPUS-CONNECT-SYIT-MANAGEMENT-SYSTEM
Campus Connect is a complete SYIT management system built with Python/Tkinter. It allows students to submit assignments, book IT lab equipment (queue included), view their timetable, check grade reports, and search the student directory.

Thrilled to share my latest project: Campus Connect, a robust desktop application designed to simplify campus life for students. Built using Python (Tkinter), this system acts as a one-stop digital hub, streamlining everything from submitting assignments to booking IT lab equipment and tracking academic performance. It was a great exercise in building a full-featured application with a user-friendly GUI.

Key Features & Personal Achievements ✨
I focused on creating intuitive, real-world solutions for common student challenges. Here's a look at the core functionality I developed:

1. Academic Dashboard & Reporting
Grade Analysis: Implemented a detailed Grade Analysis Report that gives students a clear picture of their performance—calculating overall averages, subject-wise scores, and providing a distribution of letter grades (A, B, C, etc.).

Weekly Timetable: Developed a clean, interactive view of the Weekly Timetable to help students keep track of their classes, subjects, and faculty.

2. Assignment & Submission Workflow
Assignment Management: Created a seamless process for students to submit assignments (including naming and uploading files) and easily track their submission history.

"Undo" Functionality: Added a critical feature that allows a student to quickly remove a submission with a clear confirmation, simulating a common administrative requirement.

3. IT Lab Equipment Booking
Resource Scheduling: Built a system for booking specialized IT Lab equipment (like Raspberry Pi Kits and 3D printers) by category, duration, and specific item.

Real-time Queuing: Developed a Current Booking Queue feature that informs the user of their position in line, ensuring fair and organized access to limited resources.

4. User Experience & Management
Theming & UX: Included a user-toggleable Dark/Light Mode to enhance accessibility and user comfort during extended use.

Directory Search: Created a searchable Student Directory that helps connect peers by quickly looking up contact and academic information.

Secure Authentication: Designed a full authentication system covering both Student Registration and secure login via a unique Student ID.

Technology Stack 💻
Primary Language: Python

GUI Framework: Tkinter (for a cross-platform desktop application)

Data Management: Local data structures for managing users, queues, and assignments.

This project gave me valuable experience in desktop application development, GUI design, and building data management logic to simulate a complex, multi-user environment.
